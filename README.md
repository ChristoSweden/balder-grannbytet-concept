# Grannbytet — Balder concept demo

An independent, clickable proposal for a contract-verified local reuse marketplace inside Balder's resident app.

## Important

This is an independent concept demo. It is not an official Balder service and has not been commissioned, approved or published by Fastighets AB Balder. All listings, distances, users, interactions and pilot targets are fictional examples.

The demo has no backend, payment flow, external messaging or real tenant data. Legal, privacy, moderation, accessibility, security and operational ownership require formal approval before any real pilot.

## Brand alignment

- Live-site palette: Balder burgundy `#bb0f33`, deep green `#1c3c34`, sage `#607771`, graphite `#231f20`, cool grey and white.
- Live-site typographic pattern: condensed, uppercase display headlines paired with a neutral sans-serif body. The demo uses open web-font substitutes because Balder's Graphik web fonts are proprietary.
- Live-site character: white navigation, squared controls, editorial photography, deep-green selection states and precise burgundy accents.
- All seven raster images were generated specifically for this Balder concept and are not reused from the Heimstaden or Nivika concepts.
